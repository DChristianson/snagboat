Factory Clock

Session visualizations for coding agents, part of Snagboat github.com/DChristianson/snagboat

Factory Clock is a set of visualizations of coding-agent sessions, with a carousel to move through them. Every visualizer draws the same sessions its own way. Pick which sessions above, under Sessions. It reads the event logs of Snagboat, a VS Code extension that watches Claude Code and GitHub Copilot sessions.

or drop the daily files Snagboat writes (events/YYYY-MM-DD.jsonl) here.

Files are read in this browser and nothing is sent anywhere: the page's security policy forbids network requests. In VS Code, Snagboat: Reveal Event Log Folder opens the folder the files are in.
