Snagboat

github.com/DChristianson/snagboat

The Explore tab of the Snagboat VS Code extension, in a browser, over example sessions: every visualizer draws the same sessions its own way.

or drop the daily files Snagboat writes (events/YYYY-MM-DD.jsonl) here.

Files are read in this browser and nothing is sent anywhere: the page's security policy forbids network requests. In VS Code, Snagboat: Reveal Event Log Folder opens the folder the files are in.

Example sessions: four generated ones, shaped like real Claude Code and Copilot sessions but not recorded from anyone. Load your own files above to explore yours.
